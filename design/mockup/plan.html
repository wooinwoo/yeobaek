1. 문제

가족을 잃은 직후의 한 달은 가장 슬픈 동시에 가장 복잡한 시기다. 유족은 슬퍼할 겨를도 없이 장례·행정·상속·디지털 정리를 한꺼번에 처리해야 하고, 정보는 블로그·상조사·정부24에 흩어져 있다.

특히 놓치기 쉬운 지점 (실제 경험 기반)

  • 자택 사망 시 경찰 검시가 먼저 — 시신 인도 전엔 장례 시작 불가인데 이를 모름
  • 휴대폰 지문·얼굴 잠금은 생전에만 해제 가능 — 사후엔 사진·연락처·금융앱 접근 불가
  • 계좌 동결 — 사망 인지 시 동결되며, 미리 인출은 상속인 분쟁·법적 위험
  • 상속포기의 함정 — 잘못하면 빚이 형제·조카까지 줄줄이 승계
  • 기한 — 사망신고 1개월, 상속 결정 3개월, 상속세 6개월을 놓침
  • 받을 수 있는 지원금(국민연금 사망일시금 등)을 몰라서 못 받음

2. 타깃 유저

구분상황핵심 니즈
1차 · 핵심방금 가족(부모 등)을 잃은 상주·유족 (30~60대)"지금 당장 뭘 해야 하지?" 순서·기한·서류
2차상속·빚 문제로 막막한 유족한정승인/포기 판단, 분쟁 예방
3차부모의 노년을 준비하는 자녀미리 알아두기, 체크리스트 저장

핵심 인사이트: 유족은 평생 한두 번 쓰고, 쓰는 순간 극도로 정신없고 검색할 여력이 없다. → "찾게" 하지 말고 "떠먹여" 줘야 한다.

3. 핵심 가치·차별점

  • 내 상황에 맞춘 안내 — 자택/병원, 수급자 여부, 가족 구성에 따라 필요한 일만 노출
  • 중립성 — 상조 상품을 팔지 않는다. 광고·영업 없는 객관 정보 (고이 등과의 결정적 차이)
  • 도구화 — 정적 글이 아니라 진행상황 추적·기한 알림·빚 진단 시뮬레이터
  • 위험한 속설 교정 — "계좌 미리 빼라" 같은 통념의 위험을 짚어줌
  • 위로 — 같은 길을 지난 이들의 익명 커뮤니티

4. 경쟁 환경

주체정체한계
정부24 안심상속재산 통합조회 도구조회만, 절차 안내 아님
고이(Goi)장례 가이드북·체크리스트장례상품 판매가 본체, 정적 콘텐츠
브이힐즈생전 자산 입력→사후 전달사전 준비형, 유족 길잡이 아님
법무법인 블로그SEO 콘텐츠산재, 영업 깔때기

해외 검증 모델: Cake·Empathy·Lantern (사후 체크리스트+추모+커뮤니티, 인수까지 됨). 한국 현지화가 비어있음. → 인터랙티브 중립 유족 길잡이 = 국내 공백.

5. 범위 (MVP)

기능설명우선순위
유족 체크리스트상황 맞춤 + 기한 + 진행상황 저장MVP
빚 상속 진단가족 구성 → 한정승인/포기 조합 안내MVP
용어 사전장지·봉안당·자연장 등 쉬운 설명MVP
서류 가이드사망진단서 부수·제출처MVP
지원금 진단받을 수 있는 지원 찾기v1.1
커뮤니티익명 Q&A·위로 (인증·DB 필요)v1.1
디지털 유산 정리계정·구독 정리 안내v2

MVP는 로그인 없이 동작(진행상황은 로컬 저장). 커뮤니티부터 인증·DB 도입.

6. 정보구조 (IA)

여백 (홈 / 랜딩) ├─ 유족 길잡이 ← 상황 맞춤 체크리스트 (핵심) │ ├─ 임종 직후 │ ├─ 장례 │ ├─ 행정·상속 │ └─ 마무리·디지털 ├─ 빚 상속 진단 ← 시뮬레이터 ├─ 용어 사전 ├─ 서류 가이드 ├─ 지원금 진단 └─ 커뮤니티 ← 익명 Q&A·위로

7. 핵심 플로우

① 첫 진입 (위기 상태)

랜딩 → "지금 필요한 도움" → 상황 3문항(자택/병원·수급자·가족) → 맞춤 체크리스트가 즉시 생성 → "오늘 할 일"이 맨 위.

② 빚 진단

빚>재산? → 상속인 구성 → 결과(누가 한정승인/포기) + 다음 행동(법원 신청 안내·전문가 연결).

③ 재방문

로컬 저장된 진행상황 복원 → 다음 기한 D-day 표시.

8. 데이터 모델 (스케치)

GuideTask id, stage(임종|장례|행정|마무리), title, desc deadlineRule // 예: 사망+1개월 showIf // 조건: {death:'home', recipient:true} 등 sourceUrl // 근거(정부24 등) UserProgress (로컬 or DB) deathDate, situation{death, recipient, religion} checked: [taskId...] GlossaryTerm { term, short, body, related[] } SupportProgram { name, eligibility, amount, deadline, applyUrl } Post / Comment (커뮤니티, v1.1~)

스택(무료 티어): Next.js + Supabase(인증·DB·스토리지) + Vercel. 콘텐츠는 정적(MDX/JSON)으로 시작.

9. 빚 진단 로직

  • 재산 ≥ 빚 → 단순승인 안내 (3개월 내 무대응 시 자동 단순승인 경고)
  • 빚 > 재산 → 상속인 중 1명 한정승인 + 나머지 포기 권장 (후순위 차단)
  • 모름 → 전원 신중 + 안심상속으로 재산·부채 먼저 조회 권장
  • 공통: 상속순위(직계비속→직계존속→형제자매→4촌), 배우자 공동상속, 특별한정승인(안 날부터 3개월) 설명
  • 모든 결과에 "일반 안내 · 신고 전 전문가 상담" 고지 고정

11. 리스크 · 운영 원칙

  • 정확성: 법·제도는 변한다. 모든 콘텐츠에 근거 출처 + "전문가 상담 권장" 고지. 정기 검수.
  • 법적 책임: 정보 제공 서비스 — 법률·세무 자문 대체 아님 명시.
  • 수익화 약함: 평생 1회성 사용. 포트폴리오/공익 목적이므로 OK. (장기: 비영업 제휴·후원)
  • 민감성: 광고·자극 배제. 위기 상담 번호 상시 노출. 데이터 최소 수집.
